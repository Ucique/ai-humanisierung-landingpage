# AI-Humanisierung Landingpage

Dieses Repository enthält eine professionelle Single-File-Landingpage für die Dienstleistung „AI-Humanisierung von Texten“. Die Seite ist komplett in HTML und CSS umgesetzt und kommt ohne externe Frameworks aus.

## Live-Link

Nach dem Aktivieren von GitHub Pages ist die Seite hier erreichbar:

https://ucique.github.io/ai-humanisierung-landingpage/

(Es kann einige Minuten dauern, bis der Link aktiv ist.)

## Lokale Vorschau

Um die Seite lokal zu testen, kannst du dieses Repository klonen und einen einfachen HTTP-Server starten:

```bash
git clone https://github.com/Ucique/ai-humanisierung-landingpage.git
cd ai-humanisierung-landingpage
python -m http.server 8080
```

Danach kannst du die Seite unter http://localhost:8080 im Browser öffnen.
